# OnClick Phase 1 — FINAL V3

This package is the replacement build for the OnClick GitHub Pages MVP.

## Public entry
- `index.html`

## Separate Admin portal
- `admin-login.html`
- `admin.html`

Admin accounts are backend-authorized. There is no public Admin signup.

## Phase 1
- Customer + Vendor only
- Product-first search across approved/open shops
- One shop per order
- Rs. 500 minimum order
- Payment directly to merchant
- 5% commission on product subtotal
- Vendor controls routine product changes
- Admin controls initial vendor/shop approval, moderation, account status, shop status and audit history

## Pilot
Nowshera village + Pindi Gheb City.

## Supabase
The package uses the existing project configuration in `supabase-config.js`.
Do not put any Supabase secret/service-role key in frontend files or GitHub.
